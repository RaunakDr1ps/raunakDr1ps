## Featured Project

### NIRIKSH — AI Digital Twin for Predictive Maintenance

A real-time digital twin dashboard that monitors turbofan engine health, predicts remaining useful life, and visualizes degradation patterns. Built with a modern stack and designed for production reliability.

```
┌──────────────────────────────────────────────────────────────────┐
│  Dashboard · Real-time Telemetry · ML Predictions               │
│  Live 3D Engine Visualization · Alarms · Degradation Forecasts   │
└──────────────────────────────────────────────────────────────────┘
```

**Architecture**

```
React + TypeScript ─── FastAPI ─── Python ML Pipeline ─── WebSocket
      │                    │               │                    │
  Tailwind CSS          REST API       XGBoost/LSTM          Live Data
  Framer Motion        PostgreSQL     Scikit-learn          Streaming
  Three.js             Redis         Pandas                 Updates
```

| Layer | Technology |
|---|---|
| Frontend | React, TypeScript, Tailwind CSS, Framer Motion, Three.js, Recharts |
| Backend | FastAPI, Python, WebSockets, Uvicorn, Axum |
| Machine Learning | Scikit-learn, XGBoost, LSTM, Time-series forecasting |
| Infrastructure | Docker, CI/CD, PostgreSQL, Redis |
