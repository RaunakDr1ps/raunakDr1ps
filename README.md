## Featured Project

### NIRIKSH — AI Digital Twin for Predictive Maintenance

A real-time digital twin platform that monitors turbofan engine health, predicts remaining useful life, and visualizes degradation patterns — built for reliability, not just demos.

```
┌─────────────────────────────────────────────────────┐
│  Dashboard · 3D Engine View · Live Telemetry        │
│  ML Predictions · Alarms · Degradation Forecasts     │
└─────────────────────────────────────────────────────┘
```

| Area | Stack |
|---|---|
| **Frontend** | React, TypeScript, Tailwind CSS, Framer Motion, Recharts, Three.js |
| **Backend** | FastAPI, Python, WebSockets, Uvicorn |
| **Machine Learning** | Scikit-learn, XGBoost, LSTM, Time-series forecasting |
| **Infrastructure** | Docker, CI/CD, Axum WebSocket server |
